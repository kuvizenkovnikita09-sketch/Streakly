# Streakly

Web app for tracking daily workout courses: pick a course, get a daily plan (sets and reps), log what you actually did and see how well you follow it.

## Возможности (версия 1, frontend)

- регистрация и вход (демо, данные хранятся в браузере)
- 8 курсов с фильтром по уровню, норма растёт от дня к дню
- страница «Мой день»: норма на сегодня и форма отчёта по подходам
- статистика за неделю и месяц, серия дней подряд, всего повторений
- можно проходить несколько разных курсов одновременно
- «Моя статистика»: календарь по месяцам (красный, жёлтый, зелёный и бирюзовый дни)
- боковая панель: Курсы, Мои курсы, Лидерборд, О сайте
- результат выше нормы даёт больше 100% (влияет на статистику и рейтинг)
- статистика и лидерборд отдельно для каждого курса (в рейтинге пока демо-участники)

## Структура

```
streakly/
├── run.py               запуск сервера
├── app/                 бэкенд на Flask
│   ├── __init__.py      создание приложения и базы
│   ├── models.py        таблицы (пользователи, курсы, записи на курсы, отчёты)
│   ├── seed.py          начальные данные курсов
│   └── api.py           запросы API
└── frontend/            сайт (html, css, js)
    ├── index.html, login.html, register.html, dashboard.html,
    │   stats.html, leaderboard.html, about.html
    ├── css/style.css
    └── js/              courses.js, app.js
```

## Запуск сервера

```bash
python3 -m venv venv
source venv/bin/activate
pip install flask flask-sqlalchemy
python run.py
```

Сайт откроется на http://127.0.0.1:5001, список курсов из базы: http://127.0.0.1:5001/api/courses

## Планы

- бэкенд на Flask + SQLite вместо localStorage
- настоящий рейтинг между пользователями
- статистика за год, графики
- создание своих курсов

> Сейчас пароли хранятся в браузере в закодированном виде, это только демо. С бэкендом появится нормальное хэширование.
